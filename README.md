# Cross-Management

Cross-Management is a multi-language trading showcase website with a modern UI, interactive elements, and a built-in mini-game.

The site automatically detects the user’s language and opens the appropriate version.

## Features
- Auto language detection
- Trading platforms showcase (Binary, Crypto, Forex)
- Mini-game “Trader Runner” (Canvas)
- pump.fun token quick access
- Animated dark UI with glassmorphism
- Contact modal (Telegram, WhatsApp, Instagram, Twitter)

## Tech Stack
- HTML5
- CSS3 (animations, gradients)
- JavaScript (Vanilla)
- Canvas API
- Bootstrap

## Disclaimer
This project is a demo/showcase. It is not a real trading or investment platform.
